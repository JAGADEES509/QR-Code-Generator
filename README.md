# QR Code Generator

A simple and user-friendly QR Code Generator built using HTML, CSS, and JavaScript.

## Project Screenshot

![QR Code Generator Preview](qr-generator-preview.png)

## Features

- Generate QR codes from text or URLs
- Simple and clean user interface
- Responsive layout
- Generate new QR codes for different inputs

## Technologies Used

- HTML5
- CSS3
- JavaScript
- QRCode.js library

## How to Use

1. Open the application.
2. Enter text or a URL in the input field.
3. Click **Generate QR**.
4. Your QR code will appear on the screen.
